# 重力反转 GRAVITY FLIP

霓虹赛博风的 2D 横版闯关小游戏。核心机制只有一句话：**重力可以瞬间反转**——天花板就是地板，脚下随时会变成头顶。

- 纯 Canvas 2D + 原生 JavaScript，零依赖、零构建工具、零网络请求。
- 最终产物是**单个 HTML 文件**，双击即玩，可离线、可拷贝、可放进 U 盘。
- 12 个关卡，每关 3 颗星。

## 如何游玩

直接打开构建产物：

```
dist/gravity-flip.html
```

双击，或用浏览器打开（推荐 Chrome / Edge / Firefox / Safari 最新版）。整个游戏——画面、音效逻辑、关卡数据、CSS——都内联在这一个文件里，不需要服务器，也不会发起任何外部请求。

手机上也可以用：页面适配 `viewport-fit=cover` 与安全区，底部有常驻的触屏按钮。

## 操作

| 动作 | 键盘 | 触屏按钮 |
| --- | --- | --- |
| 左移 | `←` 或 `A` | ◀ |
| 右移 | `→` 或 `D` | ▶ |
| 跳跃 | `Space` / `↑` / `W` | 跳 |
| **翻转重力** | `Z` / `↓` / `S` | 翻转（青色品红渐变那颗） |
| 暂停 | `P` | 覆盖层按钮 |
| 重开本关 | `R` | 覆盖层按钮 |

要点：

- 跳跃只能在踩实的时候用；贴墙时也能跳（墙跳）。
- 翻转是**瞬切**，不是渐变的。跳跃后立刻翻转可以多蹭约半格高度，这是很多关卡的解法关键。
- 收集齐 3 颗星之后出口才会生效，没集齐时走到门口不会通关。

## 12 关与星级

- 关卡从第 1 关逐步教学：先只有地面与重力翻转，随后加入尖刺、巡逻锯、纵向竖井与需要连续翻转的走廊。
- 难度按**实测最短路线**递增：第 1 关 3 次翻转即可通关；第 2–6 关存在 1 次翻转的最速路线（三星要求 ≤2 次）；第 7–12 关最短需要 4–10 次翻转，最难的集中在第 9 关与终章第 12 关（各需 10 次）。
- 每关最多 **3 星**，依据**通关时间**与**重力翻转次数**评定。`par` 阈值贴着实测最优解，所以三星是真的要求路线效率，而不只是「能通关」。
- 一个诚实的例外：**第 8 关在完全不翻转重力的情况下也能通关**（实测 4.65s、0 次翻转）。它是唯一一关「翻转只是优化手段、不是硬性要求」的关卡；其余 11 关禁止翻转时都搜不到通关路线。
- 关卡中途死亡次数过多会失败，需要重开本关。

## 本地存档

- 进度（已解锁关卡、每关星数、最佳时间与最佳翻转数）保存在浏览器的 `localStorage` 中，键名是 **`gravity-flip-save-v2`**。
- 关闭页面、重启浏览器都不会丢；换浏览器或换设备不会同步。
- 想清空进度：清除该站点的浏览数据即可。游戏不联网，不会上传任何数据。

## 让 AI 助手帮你装到本机（给朋友用的提示词）

这个仓库是**自解释**的：已经构建好的单文件成品就在 `dist/gravity-flip.html`，
装到本机不需要 Node、不需要 Python、不需要构建。

把下面这段整段发给你的 AI 助手（DeepSeek Harness / 任意能执行命令的助手）即可：

```text
请帮我把这个网页小游戏装到我的电脑上并打开：
仓库地址：<把这里换成仓库链接，例如 https://github.com/你的用户名/gravity-flip>

要求：
1. 优先 git clone 这个仓库；如果本机没有 git，就改用「下载 ZIP 并解压」的方式。
2. 如果 HTTPS 报证书/TLS 类错误（例如 schannel 或者代理问题），不要反复重试，
   直接告诉我需要手动下载，并给我准确的 ZIP 下载地址。
3. 装好后打开 dist/gravity-flip.html：Windows 用 start、macOS 用 open。
4. 打开前确认这个 HTML 是自包含的（文件里应该没有 src= / href= 外部请求）；
   它是单个文件，双击也能玩。
5. 不要联网安装任何依赖，也不要运行构建。
6. 最后告诉我：文件解压到了哪个目录、用什么打开的。
```

> 朋友**不需要 GitHub 账号**：公开仓库的 ZIP 下载和 clone 都不需要登录。
> 只有「想自己改动再发布」时才需要账号。
> 想让朋友也能发链接给别人玩，让他按 `SHARE.md` 的路径 C 自己部署一份即可。

## 开发与构建

```
gravity-flip/
├─ index.html          # 外壳模板（含两个占位符注释：样式 / 脚本）
├─ css/style.css       # 霓虹赛博样式，会被内联
├─ js/                 # 引擎、渲染、关卡数据
├─ build.mjs           # 构建脚本：纯字符串替换，产出 dist/gravity-flip.html
└─ README.md
```

```bash
node build.mjs
```

构建脚本做且只做两件事：

1. 把**样式占位符注释**替换为内联的样式表；
2. 把**脚本占位符注释**替换为内联的脚本。

产物写到 `dist/gravity-flip.html`。`index.html` 是模板，**不能**直接用浏览器打开当成品用（缺少样式与脚本）。
