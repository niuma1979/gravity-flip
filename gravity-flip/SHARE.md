# 怎么把《重力反转》分享到 QQ

## 先看结论（很重要）

QQ 里**直接发 `.html` 文件**给朋友，基本是玩不起来的：

- **手机 QQ**：收到 `.html` 会说"暂不支持打开该文件类型"，或者被当成普通文件下载。
  手机上也没有"用浏览器打开本地文件"这个顺畅操作 —— **手机端必须用链接**。
- **电脑 QQ**：对方另存为后**双击**能用浏览器打开，这是唯一的免部署玩法（见路径 A）。
- 另外 QQ 对 `.html` 附件有安全提示，可能提示"此文件可能不安全"。

所以对外分享，正解是：**先把游戏放上网拿到一个链接，再在 QQ 里发链接**。
链接在 QQ 内置浏览器里点开就是全屏可玩的游戏，不需要装任何东西。

---

## 路径 A：只发给用电脑的朋友（0 成本、最快）

1. 在 QQ 里直接把 `dist/gravity-flip.html` 作为文件发送。
2. 让对方**另存为**到桌面，然后**双击**（会用 Chrome/Edge 打开）。
3. 提前说一句："下载后双击打开，别在 QQ 里点预览。"

限制：对方必须在电脑上；手机端不行。

---

## 路径 B：同一个 WiFi 下先试玩（已帮你跑通，适合自测/宿舍/办公室）

不用注册任何账号，只需要对方和你连同一个 WiFi：

```bash
node tools/share_lan.mjs 8080
```

它会把 `dist/` 跑成静态服务并打印地址，例如：

```
本机自测:      http://127.0.0.1:8080/
同 WiFi 分享:  http://192.168.1.170:8080/
```

把 `http://192.168.1.170:8080/` 这条发到 QQ，同一 WiFi 下的手机点开就能玩（已实测：首页 200、分享图 200、端口在局域网可达）。

限制：**只有同一个局域网能访问**，发给外网朋友打不开；你的电脑关了服务就断。

---

## 路径 C：放上公网，发给任何人都能玩（推荐）

目标是把 `dist/` 这个**文件夹**（`gravity-flip.html` + `share-card.png`）传上去，拿到一个 `https://...` 链接。

> 为什么必须把 `share-card.png` 一起传：QQ / 微信分享时会去抓 `og:image` 做缩略图，
> 抓不到就退化成一条光秃秃的文字链接。

### C0. 最省事：网页上传 + 自动部署（不需要本地装 git）

仓库里已经放好了 GitHub Actions 工作流（`.github/workflows/pages.yml`），你只要：

1. 在 GitHub 网页上新建一个**公开**仓库（例如 `gravity-flip`）。
2. 点 **Add file → Upload files**，把整个 `gravity-flip` 文件夹里的内容拖进去
   （`.github/`、`css/`、`dist/`、`js/`、`tools/`、`index.html`、`build.mjs`、`README.md`、`SHARE.md` 都要）。
   > 浏览器上传时隐藏文件/文件夹可能选不到 `.github`，那就先传其它文件，再用
   > **Add file → Create new file**，文件名填 `.github/workflows/pages.yml`，把内容粘进去。
3. 仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。
4. 之后每次你 commit（哪怕只是在网页上改一个字），工作流会自动：
   构建单文件产物 → 跑 29 项冒烟测试 + 12 关卡角回归 + 12 关可解性 + 二维码端到端验证 → 发布。
5. 发布完成后，仓库 **Actions** 页面里能看到绿色的部署记录，链接形如
   `https://<你的用户名>.github.io/<仓库名>/`。
6. 也可以手动触发：**Actions → Build & Deploy to GitHub Pages → Run workflow**。

失败排查：Actions 里哪个步骤红了，点进去看日志；构建/测试全部在云端跑，本地不用装 Node。
（本地想先验证的话，逐条执行工作流里的命令即可，和本地完全一致。）

### C1. Cloudflare Pages（免费、国内访问通常可用、不用备案）

1. 打开 <https://dash.cloudflare.com/>，注册/登录（邮箱即可）。
2. 左侧 **Workers & Pages** → **Create** → **Pages** → **Upload assets**。
3. 项目名随便填，比如 `gravity-flip`。
4. 把 `gravity-flip/dist/` 里的**两个文件**拖进去 → **Deploy**。
5. 几十秒后拿到 `https://gravity-flip.pages.dev`，这就是你的分享链接。

> 如果不允许拖拽上传：把 `dist` 文件夹压成 zip，用 **Direct Upload (zip)** 那条路。

### C2. GitHub Pages（代码已经在 git 生态里最省事）

1. 新建一个公开仓库，把 `gravity-flip/dist/` 的文件放到仓库根目录（或 `/docs`）。
2. 仓库 **Settings → Pages → Source** 选 `main` 分支 + `/root`（或 `/docs`）→ Save。
3. 一两分钟后得到 `https://<你的用户名>.github.io/<仓库名>/`。

注意：国内访问 `github.io` 有时不稳定，发给国内朋友建议优先用 C1。

### C3. 腾讯云 COS / 对象存储静态网站（国内访问最稳，但要实名 + 自定义域名）

适合以后想认真运营一个页面的情况：国内打开快、微信里也不容易被拦。
代价是要实名认证、开静态网站功能、并且需要一个已备案的域名才能走 CDN 加速。第一次分享不建议走这条。

### C4. itch.io（顺便能在游戏社区被陌生人玩到）

打包成 zip 上传，项目类型选 **HTML**，勾选 "This file will be played in the browser"。国内访问速度一般。

## 拿到链接之后，怎么发才像样

1. **先自己点一遍链接**，确认能打开、能玩（尤其确认键盘/触屏按钮都有反应）。
2. 在 QQ 里发链接时，前面加一句钩子，例如：
   > 做了个小游戏，按一下翻转重力、天花板就是地板：<链接>
   > 12 关，每关三星，看你能不能全三星
3. 等卡片加载出来再发。如果只有一条光秃秃的文字链接，说明 `share-card.png` 没传上去或路径不对。
4. 微信里同理；微信对 `pages.dev` 这类域名一般能正常展示卡片。

## 分享卡片自检清单

部署完，用这三种方式确认卡片没问题：

- 浏览器直接打开 `https://你的域名/share-card.png` → 应该看到 1200×630 的青色名场面图。
- 浏览器查看 `https://你的域名/gravity-flip.html` 源码 → 确认 `<meta property="og:image">` 里是 `share-card.png`（相对路径即可，浏览器会自动补成绝对地址）。
- 如果分享出去还是没有缩略图：把 `og:image` 改成**绝对地址**（`https://你的域名/share-card.png`）再重新部署一次。

## 二维码分享（可选，适合当面/群里发图）

拿到公网链接后，用仓库自带的生成器做一张二维码图（零依赖，自己实现的编码器）：

```bash
node tools/make_qr.py "https://你的域名/" -o dist/qr.png --label "扫码即玩：重力反转"
```

- `--label` 会在二维码下方加一行说明文字（可选）。
- 生成的图可以直接发到 QQ 群 / 朋友圈，对方长按识别即可开玩。
- **二维码质量怎么保证的**：`python tools/make_qr.py --self-test` 会用独立解码流程往返自检；
  `node tools/qr_verify.mjs` 更进一步——用**另一个语言的独立解码器**从 PNG 像素出发，
  校验定位图案/定时图案/格式信息 BCH/Reed-Solomon 纠错码字，再把原文读回来对比。
  7 个用例（不同版本、不同尺寸、带文字卡片）全部通过才算过。
- 注意：二维码只能编码**公网链接**（路径 C）。局域网地址（路径 B）扫了也只有同 WiFi 能开。

## 常见问题

**Q：手机 QQ 里点开链接，怎么玩？**
A：点开即可，页面会全屏显示画布，底部有 ◀ ▶ 跳 翻转 四个常驻按钮。右下角那颗青粉渐变的"翻转"是核心操作。

**Q：朋友说打不开 / 一直转圈。**
A：`pages.dev`、`github.io` 在国内部分网络/部分时段会被限速。换 C1 并让对方用手机流量试一次，能区分是"域名被限"还是"文件问题"。

**Q：进度会同步吗？**
A：不会。进度存在每个人自己的浏览器 `localStorage`（键名 `gravity-flip-save-v2`），换设备/换浏览器不通用，也不会传到你这里。

**Q：能不能直接发一个二维码？**
A：可以，见上面「二维码分享」一节——仓库自带生成器，`node tools/make_qr.py "链接" -o dist/qr.png`。
二维码只能指向公网链接（路径 C）；局域网地址（路径 B）扫了也只有同 WiFi 能开。

**Q：我不想装 git，能用自动部署吗？**
A：能。GitHub 网页上直接 Upload files 就能提交，工作流会自动构建+测试+发布（见路径 C0）。

**Q：能不能塞进 QQ 小程序 / 公众号？**
A：需要企业主体和审核，个人做小游戏分享走链接最省事；真要进小程序得把游戏改造成小程序 Canvas 版本，是另一个工作量。
